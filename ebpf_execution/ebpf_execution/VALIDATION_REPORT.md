## 📊 Dashboard Metrics (Monitor)

The monitoring dashboard (`build/monitor`) displays the following metrics, updating every 500ms:

### JIT Status Box
- JIT Compilation status (ENABLED/DISABLED/UNKNOWN)
- Execution mode (Native x86-64 vs Bytecode Interpreter)
- Uptime counter
- Toggle instructions

### Performance Comparison Box
- **Throughput (M pps)**: Interpreter vs JIT with speedup factor
- **Dispatch Overhead**: ~250ns (Interpreter) vs ~5ns (JIT)
- **CPU Usage (%)**: Comparison between modes
- **I-Cache Behavior**: Technical details

### Information Box
- Commands for inspection (bpftool, perf, etc.)
- Quit instructions
