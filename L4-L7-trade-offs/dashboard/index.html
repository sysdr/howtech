Understanding the Demo

L4 Video Streaming Test

Simulates fetching 100KB video chunks through an L4 (TCP) load balancer. No HTTP parsing - just raw packet forwarding. Watch the microsecond-level latency.

L7 API Gateway Test

Routes requests to /users, /orders, /products based on URL path inspection. The L7 load balancer parses HTTP and routes intelligently. Note the millisecond latency.
